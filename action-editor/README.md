# Action Editor Tools

`.fx` tools under `toolbox/<section>/`.

User files (same paths the plugin writes under AppData):

- `action-editor/gradients.json`
- `action-editor/colors.json`
- `action-editor/curves.json`

These appear next to `toolbox/` after the first save in the editor — not inside `toolbox/`.

Authoring palette only. Finished timelines go to:

- `triggers/effects/` — Trigger actions
- `movie-sync/effects/<category>/` — Movie Sync looks
